## 1. Limits

### Definition (intuitive)
lim_(x → a) f(x) = L

Meaning:
When x is close to a then f(x) is close to L.

---

### Key Idea
- Limit depends on behavior around a point
- f(a) does NOT have to equal the limit

---

### Limit Laws
If limits exist:

- Sum:
  lim (f + g) = lim f + lim g

- Product:
  lim (f * g) = (lim f)(lim g)

- Constant:
  lim (c * f) = c * lim f

- Quotient:
  lim (f / g) = (lim f) / (lim g), if lim g ≠ 0

---

### Special Limits
- lim (x → 0) [sin(x)/x] = 1
- lim (x → 0) [x log(x)] = 0

---

## 2. Continuity

### Definition
A function is continuous at a if:

lim (x → a) f(x) = f(a)

---

### Intuition
- No jumps
- No breaks
- Smooth behavior

---

### Equivalent View
If x → a, then f(x) → f(a)

---

## 3. Properties of Continuous Functions

If f and g are continuous:

- f + g → continuous  
- f * g → continuous  
- f / g → continuous (if denominator ≠ 0)  
- f(g(x)) → continuous  

---

### Common Continuous Functions
- Polynomials  
- Exponentials  
- Logarithms  
- Trigonometric functions  

---

## 4. Discontinuity

Not continuous if:
- limit does not exist  
- limit ≠ f(a)  

---

## 5. Key Takeaways

- Limit = approaching value  
- Limit ≠ actual value  
- Continuity = limit matches value  
- Continuous functions behave smoothly
